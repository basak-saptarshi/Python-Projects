# Mean, Variance and Standard Deviation Calculator

This is a beginner Python project that calculates:

- Mean
- Variance
- Standard Deviation
- Maximum
- Minimum
- Sum

The program uses **NumPy** to perform calculations on a 3×3 matrix created from a list of 9 numbers.

## Skills Used

- Python
- NumPy
- Functions
- Arrays
- Dictionaries

## Project Type

Beginner Python Project
